# Assignment 1: Linear Algebra & Python Benchmarking

This repository contains the solutions for the first assignment of the Neural Networks course. 

## Contents

1. **Linear System Solver (`Assignment1.ipynb`)**
   - Parses a system of 3 linear equations from a text file.
   - Implements fundamental matrix and vector operations from scratch 
   - Solves the system using two different mathematical approaches:
     - Cramer's Rule.
     - Matrix Inversion (using the Adjugate Method).

2. **Performance Benchmarking (`ProgrammingChallenge.ipynb`)**
   - Focuses on optimizing the calculation of a tree's size.
   - Replaces the slow recursive DFS approach with highly optimized iterative solutions using Python's internal mechanics.
